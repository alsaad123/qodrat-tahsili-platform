## 🌟 نظرة عامة (Overview)

تم تصميم وتطوير هذه المنصة خصيصاً لمساعدة الطلاب والطالبات في المملكة العربية السعودية على الاستعداد الأمثل لاختبارات **القدرات العامة** و**التحصيلي**. تمكّن المنصة المستخدمين من رفع تجميعات الأسئلة (ملفات PDF أو صور)، واستخراج الأسئلة والخيارات والرسومات الهندسية بدقة عالية، ثم تحويلها تلقائياً إلى اختبارات تدريبية تفاعلية تحاكي بيئة قياس الحقيقية.

---

## ✨ أبرز المميزات (Key Features)

### 1. 📄 استخراج ذكي للأسئلة (Smart Question Extraction)
- دعم رفع ملفات **PDF** أو **الصور** بجميع الصيغ الشائعة.
- استخراج فوري للنصوص والجداول والخيارات باستخدام تقنيات OCR ونماذج الرؤية الحاسوبية من **Gemini AI**.
- التعرف الدقيق على الأسئلة الكمية واللفظية وأسئلة التحصيلي (رياضيات، فيزياء، كيمياء، أحياء).

### 2. ✂️ أداة مراجعة وقص الصور المتقدمة (Advanced Review & Cropper)
- واجهة مراجعة سهلة لتعديل نصوص الأسئلة، الخيارات، وتحديد الإجابة الصحيحة وشرح الحل.
- أداة قص مدمجة مخصصة لاقتصاص الأشكال الهندسية، الرسوم البيانية، والمسائل الرياضية وإرفاقها مباشرة مع السؤال.

### 3. ✍️ مسودة حل تفاعلية (Interactive Scratchpad)
- لوحة رسم وكتابة مدمجة داخل كل سؤال تتيح للطالب التدوين وحل المعادلات الحسابية والمسائل الهندسية بالقلم مباشرة كما في الاختبار الحقيقي.

### 4. ⏱️ محاكاة واقعية للاختبار (Realistic Exam Simulation)
- مؤقت زمني دقيق لمراقبة الوقت وتدريب الطالب على إدارة الوقت.
- شريط تنقل سلس بين الأسئلة.
- إمكانية تمييز الأسئلة للرجوع إليها لاحقاً (Flag for Review).
- تجربة اختبار خالية من المشتتات لزيادة التركيز.

### 5. 📊 تحليل تفصيلي للنتائج (In-Depth Analytics)
- حساب النسبة المئوية ومستوى الأداء بدقة.
- مراجعة كاملة لجميع الأسئلة مع مقارنة إجابة الطالب بالإجابة الصحيحة.
- توضيح وشرح خطوات الحل لكل سؤال لتعزيز التعلم الذاتي.

### 6. 💾 إدارة وحفظ الاختبارات (Exam Management)
- حفظ الاختبارات محلياً مع إمكانية استئناف التدريب في أي وقت.
- سجل كامل للاختبارات السابقة والدرجات المحققة.

### 7. 🖨️ تصدير احترافي للنتائج (PDF Export)
- إمكانية تصدير الاختبار أو تقرير النتائج النهائي إلى ملف PDF منظم وقابل للطباعة أو المشاركة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):**
  - [React 19](https://react.dev/) - أحدث إصدارات ريآكت لتجربة مستخدم فائقة السرعة.
  - [TypeScript](https://www.typescriptlang.org/) - لكتابة كود متين وخالٍ من الأخطاء.
  - [Vite](https://vitejs.dev/) - بيئة تطوير وبناء سريعة وعصرية.
  - [Tailwind CSS v4](https://tailwindcss.com/) - تصميم عصري وتجاوب كامل مع كافة أحجام الشاشات.
  - [Lucide React](https://lucide.dev/) - أيقونات تفاعلية واضحة وأنيقة.
  - [Motion](https://motion.dev/) - حركات وتأثيرات بصرية انسيابية.
  - [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) - احتفال بالنتائج والتفوق.

- **الواجهة الخلفية والذكاء الاصطناعي (Backend & AI):**
  - [Node.js](https://nodejs.org/) & [Express](https://expressjs.com/) - خادم وسيط آمن لمعالجة الطلبات.
  - [Google Gen AI SDK (@google/genai)](https://www.npmjs.com/package/@google/genai) - للتواصل مع نماذج Google Gemini.
  - [PDF.js](https://mozilla.github.io/pdf.js/) & [Tesseract.js](https://tesseract.projectnaptha.com/) - لقراءة واستخراج النصوص والصفحات من المستندات.

## 🚀 طريقة التثبيت والتشغيل المحلي (Getting Started)

### المتطلبات الأساسية (Prerequisites)
- تثبيت **[Node.js](https://nodejs.org/)** (الإصدار 18 أو أحدث).
- مفتاح **Gemini API Key** (يمكن الحصول عليه مجاناً عبر [Google AI Studio](https://aistudio.google.com/)).

### خطوات التثبيت:

1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/alsaad123/qodrat-tahsili-platform.git
   cd qodrat-tahsili-platform
   ```

2. **تثبيت الحزم والمكتبات (Install Dependencies):**
   ```bash
   npm install
   ```

3. **إعداد المتغيرات البيئية (Configure Environment Variables):**
   - قم بنسخ ملف `.env.example` إلى ملف جديد باسم `.env`:
     ```bash
     cp .env.example .env
     ```
   - افتح ملف `.env` وضع مفتاح الـ API الخاص بك:
     ```env
     GEMINI_API_KEY=your_actual_gemini_api_key_here
     PORT=3000
     ```

4. **تشغيل المشروع في وضع التطوير (Run Development Server):**
   ```bash
   npm run dev
   ```

5. **فتح المنصة:**
   افتح المتصفح على الرابط:
   ```
   http://localhost:3000
   ```
